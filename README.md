# Аналитика транзакций

## Описание

 *В данном приложение доступно несколько процедур по анализу транзакций
 выгруженных в формате .xlsx*
 
1. Формирование блока со следующей информацией:
    ```   
     - общие сумы расходов по каждой карте
     - топ-5 транзакций по сумме платежа
     - курс валют
     - стоимость акций из S&P500
    ```

2. Инвесткопилка:
    ```
     - предоставляет возможность посмотреть возможные накопления за
       указанный период в случае использования услуги.
    ```

3. Формирование отчета о тратах по категории.
    ```
    - Расчитывает суму трат по указанный категории
      за 3 месяца до выбранной даты   
    ```

## Установка и использование

### Установка зависимостей
Команда для установки зависимостей из файла poetry.lock 
```
poetry install
```

### Подготовка к работе с файлом
```
Для работы с выгруженным xlsx файлом, необходимо поместить его в 
папку \data в корне проекта.
```

### Запуск программы
```
Запуск программы осуществляется через модуль main.py в корне проекта
```
